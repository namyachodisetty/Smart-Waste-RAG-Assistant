Build a complete working web application called:

“AI-Powered Smart Waste Segregation & Recycling Assistant”

This is a student project for an AI + Sustainability internship.

IMPORTANT:
The project must use a REAL Retrieval-Augmented Generation (RAG) workflow. Do not create only a normal chatbot.

PROJECT PURPOSE:
Users should be able to enter a waste item or question, and the application should identify the appropriate waste category and provide responsible disposal guidance.

Example:
User: “I have a broken mobile charger. What should I do?”

The application should retrieve relevant information from a waste knowledge base and then generate the final answer using the retrieved information.

CORE RAG WORKFLOW:

User Question
→ Retrieve relevant information from knowledge base
→ Pass retrieved information as context to AI
→ Generate final response
→ Display answer and retrieved evidence

KNOWLEDGE BASE:

Create a file:

waste_knowledge_base.csv

Include at least 40 waste-related entries.

Columns:

Waste Item
Category
Disposal Method
Reason
Safety Guidance
Sustainability Impact

Include examples covering:

- Food waste
- Banana peels
- Vegetable waste
- Paper

- Plastic bottles
- Plastic containers
- Glass bottles
- Metal cans
- Clothes
- Batteries
- Mobile phones
- Chargers
- Earphones
- Electronic devices
- Expired medicines
- Used tissues
- Mixed waste
- Other common household and campus waste

RAG IMPLEMENTATION:

Implement an understandable retrieval system.

The system should:

1. Receive the user's waste question.
2. Search the waste_knowledge_base.csv.
3. Retrieve the most relevant entries.
4. Pass those retrieved entries as context to the AI model.
5. Generate the final response based on the retrieved context.
6. Display the retrieved information as evidence.

Do not hard-code answers for individual example questions.

The retrieval process must actually use the knowledge base.

AI MODEL:

Use an AI model for the generation step.

Prefer IBM Granite if an accessible IBM watsonx/Granite API is available.

Keep the AI provider configurable using environment variables.

Do not hard-code API keys.

If an external AI API is not configured, the application should still demonstrate the retrieval portion of the RAG pipeline and clearly indicate that AI generation requires configuration.

Do not require an OpenAI API key by default.

“RAG Evidence / Retrieved Information”

This section must show the actual knowledge-base information retrieved for the user's question.

Example:

User:
“I have a broken mobile charger.”

Retrieved information:
Waste Item: Broken mobile charger
Category: E-waste
Disposal Method: E-waste collection
Reason: Electronic components require specialized handling

Generated response:

Category: E-waste

Recommended Disposal:
Use an appropriate e-waste collection facility rather than regular waste bins.

Why:
Electronic components require specialized handling.

Safety:
Do not dismantle, burn, or dispose of electronic components improperly.

Sustainability Impact:
Proper e-waste collection supports responsible recovery and disposal.
