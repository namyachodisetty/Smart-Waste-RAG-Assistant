# AI-Powered Smart Waste Segregation & Recycling Assistant

An AI-powered RAG assistant that helps users identify the correct waste category and understand responsible disposal methods.

## SDG
SDG 12 – Responsible Consumption and Production

## Features
- Waste item classification
- RAG-based knowledge retrieval
- Disposal recommendations
- Safety guidance
- Retrieved evidence for transparency

## Tech Stack
- TypeScript
- Node.js
- RAG
- AI/LLM integration
- GitHub

## Project Purpose
The system helps users make better waste segregation and disposal decisions for confusing or special waste items.
